# TP Réseaux mobiles 4G/5G — environnement Simu5G

Environnement de simulation prêt à l'emploi (OMNeT++ 6.1 + INET 4.5.4 + Simu5G 1.3.0 + JupyterLab).

## Étudiants : démarrer en 2 clics
1. Bouton vert **Code** → onglet **Codespaces** → **Create codespace on main**.
2. Attendez 1-2 min : VS Code s'ouvre dans le navigateur, un onglet JupyterLab s'ouvre automatiquement.
   Le terminal (menu Terminal → New Terminal) est déjà dans l'environnement Simu5G, dossier `/tp`.

Les sujets sont dans `tp/TPx_.../TPx_sujet.md`. En fin de séance, sauvegardez votre travail :
**Source Control** (icône à gauche) → message → **Commit** → **Sync**.
